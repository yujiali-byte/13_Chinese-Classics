# 每日诗文晨读

每日一篇诗词歌赋，一段《古文观止》，保存完整原文、注释、白话译文与评价赏析。

## 两个板块

- **诗词歌赋**：选自《诗经》《楚辞》及历代诗、词、曲、赋。短篇刊载全文，长篇按语意分段，连续各期依原文顺序刊完。
- **《古文观止》选段**：选取通行本实际收录篇章中语意完整的短段，通常约100—250字；短篇可以全文。节选注明范围及必要上下文。

## 每期内容

1. 篇名、作者或原始出处，以及简短必要背景。
2. 原文。
3. 关键注释，包括影响理解的古义、典故、难句及必要读音。
4. 覆盖本期全部原文的白话译文。
5. 评价与赏析：优先采用可核实的名家点评，并区分原话、观点转述和本期赏析。
6. 可点击的来源，以及选文和连载记录。

## 归档方式

成品使用UTF-8 Markdown，按北京时间日期保存：

`daily/YYYY-MM-DD.md`

每个日期文件同时包含两个板块的完整内容。写入后回读核对正文；已有完整同日成品时复用，保留已有修改。

连载记录包括作品、底本、本期编号和总期数、本期起止句、下一期起句及是否完结。接续以实际刊载内容为准。

## 阅读说明

名家点评注明评论者、著作和可核实的来源；未找到可靠点评时，明确说明并提供标为“本期赏析”的分析。不同版本不混拼，重要异文酌加注释。

这里保存的是阅读材料，文件存在不代表读者已经阅读或完成学习。
